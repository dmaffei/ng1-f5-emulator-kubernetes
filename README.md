# ng1-f5-emulator-kubernetes

Translates Kubernetes LoadBalancer Services and Ingress rules into F5 BIG-IP
iControl REST objects, enabling nGeniusONE BIG-IP® Discovery to monitor
Kubernetes workloads without any changes to the cluster.

## Quick Start

```bash
git clone https://github.com/dmaffei/ng1-f5-emulator-kubernetes.git
cd ng1-f5-emulator-kubernetes

# 1. Create K8s service account (see INSTALL.md Step 2)
kubectl apply -f - < rbac/netscout-ng1-rbac.yml

# 2. Export token and CA cert
kubectl get secret netscout-ng1-token -n kube-system \
  -o jsonpath='{.data.token}' | base64 -d > kubeconfig/token
kubectl get secret netscout-ng1-token -n kube-system \
  -o jsonpath='{.data.ca\.crt}' | base64 -d > kubeconfig/ca.crt

# 3. Run installer
bash install.sh
```

See **[INSTALL.md](INSTALL.md)** for full prerequisites and step-by-step instructions.

## How it works

```
nGeniusONE BIG-IP® Discovery
        │  HTTPS (F5 iControl REST)
        ▼
tmos-shim-kubernetes  (Docker container)
        │  HTTPS (Kubernetes API — read-only)
        ▼
Kubernetes API Server
  ├── LoadBalancer Services  → Virtual Servers (VIPs)
  ├── Endpoints (pod IPs)    → Pool members
  └── Ingresses              → Additional Virtual Servers
```

## Kubernetes → F5 mapping

| Kubernetes | nG1 sees (F5 BIG-IP) |
|---|---|
| LoadBalancer Service port | Virtual Server |
| Ingress rule | Virtual Server |
| Endpoint pod IPs | Pool members |
| Pod readiness | Member state (up/down) |

## Event-driven updates

Two background watch threads (services + endpoints) detect changes in real time.
On any ADDED / MODIFIED / DELETED event the in-memory cache is refreshed and
nG1 is triggered to re-poll immediately — new services appear in BIG-IP
Discovery within seconds, no manual intervention required.

## Naming convention

| Object | Format | Example |
|---|---|---|
| Virtual Server | `k-{svc-name}-{port}` | `k-traefik-80` |
| Server Pool | `sp-{svc-name}-{port}` | `sp-traefik-80` |

## nG1 BIG-IP Discovery settings

| Field | Value |
|---|---|
| Host | Docker host IP |
| Port | `8447` (default) |
| Username | `admin` |
| Password | `netscout1` |
| Login Provider | `tmos` |

## Requirements

- Docker 20.10+ with Compose v2
- Kubernetes 1.20+ with MetalLB or equivalent LoadBalancer controller
- nGeniusONE 6.3+ with BIG-IP® Discovery licensed
- Network path: Docker host → K8s API server, Docker host → nG1, nG1 → Docker host
